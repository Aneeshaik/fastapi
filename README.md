# Payments API

A small backend service for creating and retrieving payment records, built to practice a raw-SQL-first backend stack, no ORM.

## Tech Stack

- **FastAPI** — async web framework
- **aiosql** — named SQL queries loaded from `.sql` files, turned into async Python functions
- **asyncpg** — async PostgreSQL driver
- **Alembic** — database schema migrations
- **uv** — dependency and environment management

## Project Structure

```
payments-api/
├── app/
│   ├── main.py          # FastAPI app, routes, lifespan-managed DB pool
│   ├── db.py             # aiosql query loading + asyncpg connection pool
│   ├── settings.py       # environment-based configuration
│   └── queries/
│       └── payments.sql # named SQL queries (aiosql syntax)
├── alembic/
│   ├── sql/               # raw SQL files used by migrations
│   └── versions/          # migration files
├── pyproject.toml
└── uv.lock
```

## Setup

**1. Install dependencies**
```bash
uv sync
```

**2. Start a local Postgres instance**
```bash
docker run -d --name payments-db -p 5432:5432 \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=payments \
  postgres
```

**3. Configure environment variables**

Create a `.env` file in the project root:
```
DATABASE_URL=postgresql://postgres:password@localhost:5432/payments
```

**4. Run migrations**
```bash
uv run alembic upgrade head
```

**5. Start the app**
```bash
uv run uvicorn app.main:app --reload
```

API docs available at `http://localhost:8000/docs`.

## Endpoints

| Method | Path                    | Description              |
|--------|-------------------------|---------------------------|
| GET    | `/health`               | Health check              |
| POST   | `/payments`              | Create a payment          |
| GET    | `/payments/{payment_id}` | Fetch a payment by ID     |

## Migrations

Migrations are written by hand rather than autogenerated, since the project doesn't use an ORM. Each migration reads its SQL from a corresponding file under `alembic/sql/`.

To create a new migration:
```bash
uv run alembic revision -m "description of change"
```

To roll back the most recent migration:
```bash
uv run alembic downgrade -1
```
